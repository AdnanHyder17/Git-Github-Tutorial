# Git Tutorial — Jupyter Notebook Course

This repository contains 10 Jupyter notebooks, progressing from Git fundamentals to advanced recovery workflows.

## Contents

1. Introduction to Git
2. Git Configuration
3. Basic Git Commands
4. Working with Repositories
5. Staging and Committing
6. Understanding Branches
7. Merging Branches
8. Remote Repositories
9. GitHub Collaboration
10. Undoing Changes

## How to use

- Open the `.ipynb` files in Jupyter Notebook, JupyterLab, or Visual Studio Code.
- Read Markdown explanations and run command examples in your terminal.
- Code cells contain Git commands for reference; Git commands are not Python code, so run them in PowerShell, Command Prompt, Git Bash, macOS Terminal, or Linux Terminal rather than executing them as Python cells.
- Each notebook contains Windows screenshot placeholders. Insert an Image cell immediately below each placeholder and add a screenshot of the Windows terminal showing the command and its output.
- Replace example usernames, emails, and repository URLs with your own values.

## Compatibility

Git concepts and commands are covered for Windows, macOS, and Linux.

## Safety

Practice destructive commands such as `git reset --hard` only in a disposable repository. Never include passwords, access tokens, private keys, or other secrets commits.
